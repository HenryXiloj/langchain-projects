# LangChain Projects

A small collection of 4 LangChain projects. Each folder is a complete, runnable project.

## Projects

- [langchain-rag-demo](langchain-rag-demo/README.md) - RAG demo using OpenAI + Pinecone.
- [langchain-rag-pgvector](langchain-rag-pgvector/README.md) - RAG demo using Ollama or OpenAI + PostgreSQL + pgvector.
- [langchain-tavily-search-agent](langchain-tavily-search-agent/README.md) - Web search agent using Tavily + LangChain.
- [ai-website-security-checker](ai-website-security-checker/README.md) - AI-assisted website security checker using FastAPI, LangGraph, OpenAI, and Google Safe Browsing.

## Quick Start

1. Open a project folder.
2. Follow that project's `README.md`.

## Notes

- Keep `.env` files local; never commit secrets.
- Each project can have its own Python version and dependencies.
